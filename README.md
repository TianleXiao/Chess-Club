## Overview

**Chess Club BDC** is a clean and elegant chess web application designed for both casual players and serious enthusiasts. Built with performance and user experience in mind, it delivers a smooth, responsive, and visually pleasing chess environment.

**Live Demo**: [https://chess-club-bdc.pages.dev/](https://chess-club-bdc.pages.dev/)

## Quick Start

1. Visit [https://chess-club-bdc.pages.dev/](https://chess-club-bdc.pages.dev/)
2. Click **"New Game"** or **"Enter Game"**
3. Choose your color and start playing
