# Chess Club BDC

A modern, high-performance online chess platform built for serious players.

---

## Overview

**Chess Club BDC** is a clean, responsive, and elegantly designed chess web application developed to provide a smooth and immersive playing experience. Whether for casual games or serious practice, the platform focuses on performance, usability, and visual clarity.

Hosted at: [https://chess-club-bdc.pages.dev/](https://chess-club-bdc.pages.dev/)

---

## Key Features

- **High-quality Chessboard**: Smooth drag-and-drop interaction with professional-grade piece movement and animations
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Clean Interface**: Minimalist design that keeps the focus on the game
- **Fast Performance**: Lightweight architecture ensuring quick load times and fluid gameplay
- **Multi-device Support**: Play seamlessly across different screen sizes and input methods

---

## Technology Stack

- Modern frontend framework
- Responsive CSS architecture
- Optimized game logic and state management
- Progressive Web App (PWA) ready

---

## Quick Start

1. Visit [https://chess-club-bdc.pages.dev/](https://chess-club-bdc.pages.dev/)
2. Click **"New Game"** to start playing immediately
3. Choose your preferred side and game settings
4. Begin your match

No registration or installation required.
