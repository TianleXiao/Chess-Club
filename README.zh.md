## 项目介绍

**Chess Club BDC** 是一款简洁优雅的在线棋类 Web 应用，致力于为休闲玩家和严肃棋手提供流畅、响应迅速且视觉舒适的弈棋体验。

**在线体验**： [https://chess-club-bdc.pages.dev/](https://chess-club-bdc.pages.dev/)

## 核心特性

- **专业棋盘体验** — 流畅的拖拽落子、真实棋子动画和高品质视觉反馈
- **完全响应式** — 完美支持桌面、平板和手机端
- **极简优雅设计** — 专注于棋局本身，无任何干扰
- **轻量高性能** — 加载快速，交互丝滑
- **无需注册** — 立即开始对局

## 快速开始

1. 访问 [https://chess-club-bdc.pages.dev/](https://chess-club-bdc.pages.dev/)
2. 点击 **“开始对局”** 或 **“新游戏”**
3. 选择执棋颜色即可开始
